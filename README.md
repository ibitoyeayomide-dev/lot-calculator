# Lot Size Calculator

A phone-friendly lot size calculator for MetaTrader 5.

Open it here: https://ibitoyeayomide-dev.github.io/lot-calculator/

Enter your balance, risk percent, entry price and stop loss. The page works out the lot size for gold, NAS100, EURUSD and other symbols, including naira accounts.

The conversion rate is fetched automatically from a public market FX feed. If your prop firm uses a fixed rate, tap **Use my rate** and type that rate in. Your override is remembered in this browser.

This page does not place trades and does not connect to your broker.
